# BMPビューアーの作成 - Day12

Lazarusチャレンジ12日目です。今回は、**BMP画像を表示するシンプルなビューアー**を作成することにしました。画像ファイルを開いて表示する機能を実装しました。

## 今回の目標

今回作成するBMPビューアーは、BMP形式の画像ファイルを開いて表示するシンプルなアプリです。複雑な機能は不要で、基本的な画像表示機能に特化したアプリを目指しました。

以下の機能を実装することにしました：

- **ファイルを開く**: BMP画像ファイルを開く機能
- **画像表示**: 開いた画像を表示する機能
- **シンプルなUI**: 必要最小限のUIコンポーネント
- **軽量**: 余計な機能を排除した軽量なアプリ

## LazManagerを使ったプロジェクト作成

まず、LazManagerを起動して、プロジェクト名に「**day012_BmpViewer**」と入力し、プロジェクトを作成しました。

「**Cursor**」ボタンを押してCursorを起動し、プロジェクトフォルダを開きました。

## Cursorへのプロンプト投入

BMPビューアーの開発は、以下のようなプロンプトを投入しました：

```
Bmp Viewer
```
もう、アプリ名のみですね。ちょっと夜になって疲れてきております。

基本的なコーディングが完了するまで待ちます。
メニューが設定されていませんので、IDEを開き
Menuプロパティを設定します。

そしてビルドをいつものようにお願いします。
パスはLazarusをインストールしたときのフォルダ名に合わせる必要がありますが、
デフォルトのインストール先はC:\Lazarusになっています。

```
C:\Lazarus\Lazbuildでビルド
```

このプロンプトで、基本的なBMPビューアー機能が実装されました。ファイルを開く機能と画像表示機能が実装され、BMP画像を表示できるようになりました。

## 技術的なポイント

BMPビューアーの実装では、以下の技術的なポイントがありました：

- **TImageコンポーネント**: LazarusのTImageコンポーネントを使用して画像表示機能を実装
- **ファイルダイアログ**: ファイルを開くためのダイアログを使用
- **画像読み込み**: BMP画像ファイルの読み込み機能を実装
- **シンプルなUI**: 必要最小限のUIコンポーネントのみを使用
- **軽量設計**: 余計な機能を排除して、軽量なアプリを実現

## 学んだこと

Day12の開発を通じて、以下のことを学びました：

### BMP以外の表示について

TImageはBMP以外の表示ができないのです。
pngやjpegを表示するには内部的に変換しないといけないです。
セカンドモニタービューワーというアプリを開発中なのですが、
なんでも表示することができるようにするためには作りこみをしないとうごかないですね。
