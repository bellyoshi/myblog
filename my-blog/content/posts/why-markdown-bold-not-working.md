# HugoでMarkdownの**が強調表示されない理由と解決方法

Hugoでブログを書いていると、時々 `**` で囲んだテキストが強調表示されず、そのまま `**` が表示されてしまうことがあります。特に日本語のテキストでよく発生するこの問題について、原因と解決方法を説明します。

## 問題の例

以下のようなMarkdownを書いたとします：

```markdown
ですが、2026年の私は一味違います。**「Lazarusで100日間、毎日アプリを作る」**という、正気の沙汰とは思えないチャレンジを課すことにしました。
```

期待される結果は、`「Lazarusで100日間、毎日アプリを作る」` の部分が**太字**で表示されることです。しかし、実際には `**` がそのまま表示されてしまうことがあります。

## なぜ起こるのか？

### 1. HugoのMarkdownパーサー「Goldmark」の仕様

Hugoはデフォルトで **Goldmark** というMarkdownパーサーを使用しています。Goldmarkは、Markdownの記法を解析してHTMLに変換する際、**単語境界**を基準に強調記法を認識します。

### 2. 日本語テキスト特有の問題

日本語は**全角文字**を使用しますが、`**` は**半角文字**です。Goldmarkは、全角文字と半角文字が直接隣接している場合、単語境界として認識しないことがあります。

具体的には：
- `**` の前に全角文字（句読点、漢字、ひらがななど）がある
- `**` の後に全角文字がある

このような場合、Goldmarkは `**` を強調記号として認識せず、通常のテキストとして扱ってしまいます。

### 3. 動作する場合と動作しない場合

#### ✅ 動作する例

```markdown
- **高速性**: 数千ページでも数秒でビルド完了
- **シンプル**: 設定ファイルが少なく、学習コストが低い
```

リスト項目内では、`**` の前後にスペースがあるため、正しく認識されます。

#### ❌ 動作しない例

```markdown
ですが、2026年の私は一味違います。**「Lazarusで100日間、毎日アプリを作る」**という、正気の沙汰とは思えないチャレンジを課すことにしました。
```

段落内で、`**` が全角文字と直接隣接しているため、認識されません。

## 解決方法

### 方法1: `**` の前後にスペースを追加する（推奨）

最も簡単で確実な方法は、`**` の前後にスペースを追加することです。

**修正前：**
```markdown
ですが、2026年の私は一味違います。**「Lazarusで100日間、毎日アプリを作る」**という、正気の沙汰とは思えないチャレンジを課すことにしました。
```

**修正後：**
```markdown
ですが、2026年の私は一味違います。 **「Lazarusで100日間、毎日アプリを作る」** という、正気の沙汰とは思えないチャレンジを課すことにしました。
```

これで、`**` が正しく強調記号として認識され、`<strong>` タグに変換されます。

### 方法2: HTMLタグを直接使用する

Hugoの設定で `unsafe = true` が有効になっている場合、HTMLタグを直接使用することもできます。

```markdown
ですが、2026年の私は一味違います。<strong>「Lazarusで100日間、毎日アプリを作る」</strong>という、正気の沙汰とは思えないチャレンジを課すことにしました。
```

ただし、この方法はMarkdownの記法から外れるため、方法1を推奨します。

### 方法3: Hugoの設定を調整する

`hugo.toml` でGoldmarkの設定を調整することもできますが、日本語テキスト特有の問題を完全に解決するのは難しい場合があります。

```toml
[markup]
  [markup.goldmark]
    [markup.goldmark.renderer]
      unsafe = true
    [markup.goldmark.parser]
      autoHeadingID = true
```

## まとめ

- **原因**: Goldmarkが全角文字と半角文字の直接隣接を単語境界として認識しない
- **解決方法**: `**` の前後にスペースを追加する（最も簡単で確実）
- **推奨**: Markdownの記法を維持しつつ、スペースを追加する方法

日本語でブログを書く際は、`**` の前後にスペースを入れる習慣をつけると、この問題を避けることができます。見た目にはほとんど影響がないので、安心して使用できます。
