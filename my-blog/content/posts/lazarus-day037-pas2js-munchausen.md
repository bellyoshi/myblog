# Pas2JSで8進数ミュンヒハウゼン数（8桁固定）を探索する - Day37

Lazarusチャレンジ37日目です。**ミュンヒハウゼン数**（各桁を「その数字で累乗」した和が元の数と一致する数）を、**8進数・8桁固定** の条件で Pas2JS で探索するアプリを作りました。見つかった数について、どう計算するとその数になるか式も表示します。

## ミュンヒハウゼン数のおさらい

- **10進数**では、すでに多くの人が周知のとおり、**1** と **3435**（3³+4⁴+3³+5⁵）が有名です。0^0=1 と定義すると **438579088** も成立します。
- **16進数**では、1 や C76712FFC311E6E(16進数) など、基数を変えると別の解が現れます。
- **8進数**では、普通に（桁数を表記どおりに）やると **1** しか出てきません。

そこで **固定長8桁・先頭の0も桁として扱う・0^0=1** という条件で探索しました。8進数なので 00000000 ～ 77777777 の範囲です。

## 作成したアプリの機能

- **8進数8桁固定**で、各桁 d に対して d^d の和を計算（0^0=1）
- その和が元の数（10進数）と一致するものを探索
- 発見時に **8進数表記** と **10進数** に加え、**どの桁の累乗を足すとその数になるか** の式を表示
- ブラウザが固まらないよう、`requestAnimationFrame` でバッチ処理しながら非同期探索

## 探索結果（8進数 8桁固定・0^0=1）

範囲 00000000 ～ 77777777 で探索した結果、次の **3つ** が見つかりました。

| 8進数(8桁) | 10進数 | 計算式 |
|------------|--------|--------|
| 00000010   | 8      | 0⁰+0⁰+0⁰+0⁰+0⁰+0⁰+1¹+0⁰ = 8 |
| 00000412   | 266    | 0⁰+0⁰+0⁰+0⁰+0⁰+4⁴+1¹+2² = 266 |
| 00266222   | 93330  | 0⁰+0⁰+2²+6⁶+6⁶+2²+2²+2² = 93330 |

（表内は 0^0=1 を 0⁰ と表記しています。）

```

```

## 実装のポイント

- **累乗キャッシュ**: 0^0=1, 1^1=1, 2^2=4, …, 7^7=823543 を配列に事前計算し、ループ内では配列参照のみにしています。
- **8桁固定**: 数値が小さくても必ず8回桁を取り出し、足りない上位桁は 0 として 0^0=1 を加算します。
- **式の表示**: 一致したとき、各桁を「d^d」の形で並べて「= 10進数」と表示するようにしています。

HTML / CSS / JavaScript を分離した構成にしてあり、Pas2JS で検討したロジック（8桁固定分解と累乗和の判定）を JavaScript に移植してブラウザで動かしています。
