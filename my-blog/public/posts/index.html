期待される結果は、「Lazarusで100日間、毎日アプリを作る」 の部分が太字で表示されることです。しかし、実際には ** がそのまま表示されてしまうことがあります。

なぜ起こるのか？

1. HugoのMarkdownパーサー「Goldmark」の仕様

Hugoはデフォルトで Goldmark というMarkdownパーサーを使用しています。Goldmarkは、Markdownの記法を解析してHTMLに変換する際、単語境界を基準に強調記法を認識します。

2. 日本語テキスト特有の問題

日本語は全角文字を使用しますが、** は半角文字です。Goldmarkは、全角文字と半角文字が直接隣接している場合、単語境界として認識しないことがあります。

具体的には：

  • ** の前に全角文字（句読点、漢字、ひらがななど）がある
  • ** の後に全角文字がある

このような場合、Goldmarkは ** を強調記号として認識せず、通常のテキストとして扱ってしまいます。

3. 動作する場合と動作しない場合

✅ 動作する例

- **高速性**: 数千ページでも数秒でビルド完了
- **シンプル**: 設定ファイルが少なく、学習コストが低い

リスト項目内では、** の前後にスペースがあるため、正しく認識されます。

❌ 動作しない例

ですが、2026年の私は一味違います。**「Lazarusで100日間、毎日アプリを作る」**という、正気の沙汰とは思えないチャレンジを課すことにしました。

段落内で、** が全角文字と直接隣接しているため、認識されません。

方法1: ** の前後にスペースを追加する（推奨）

Hugoでブログを始めよう - 初心者ガイド

Hugoでブログを始めよう - 初心者ガイド

前回の投稿でHugoについて少し触れましたが、今回は実際にHugoを使ってブログを作成する方法を詳しく説明します。

Hugoとは？

Hugoは、Go言語で書かれた高速な静的サイトジェネレーターです。MarkdownファイルからHTMLサイトを生成し、以下のような特徴があります：

  • 高速性: 数千ページでも数秒でビルド完了
  • シンプル: 設定ファイルが少なく、学習コストが低い
  • 柔軟性: 豊富なテーマとカスタマイズオプション
  • 多言語対応: 国際化に優れている

インストール方法

Windowsの場合

# Chocolateyを使用
choco install hugo-extended

# または、公式サイトからダウンロード
# https://gohugo.io/installation/windows/

macOSの場合

# Homebrewを使用
brew install hugo

Linuxの場合

# Snapを使用
sudo snap install hugo

# または、パッケージマネージャーで
sudo apt install hugo

新しいサイトの作成

インストールが完了したら、新しいサイトを作成できます：

# 新しいサイトを作成
hugo new site my-blog

# サイトディレクトリに移動
cd my-blog

# テーマを追加（例：Ananke）
git init
git submodule add https://github.com/theNewDynamic/gohugo-theme-ananke.git themes/ananke

# 設定ファイルにテーマを指定
echo 'theme = "ananke"' >> hugo.toml

最初の投稿を作成

# 新しい投稿を作成
hugo new posts/my-first-post.md
