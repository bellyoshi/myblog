暗号化テキストエディタの作成 - Day17

Lazarusチャレンジ17日目です。今回は、暗号化テキストエディタを作成しました。DCPcryptパッケージを使用して、AES-256アルゴリズムでテキストを暗号化・復号化できるエディタを実装しました。

今回の目標

今回作成する暗号化テキストエディタは、以下の機能を実装することを目指しました：

  • 暗号化保存: テキストを暗号化してテキストファイルとして保存
  • 復号化読み込み: 暗号化されたファイルをパスワードで復号化して表示
  • 通常のテキストファイル: メモ帳などで開くと暗号化された文字列として表示
  • AES-256暗号化: 強固な暗号化アルゴリズムを使用
  • Base64エンコード: バイナリデータをテキスト形式で保存

LazManagerを使ったプロジェクト作成

まず、LazManagerを起動して、プロジェクト名に「day017_CryptEditor」と入力し、プロジェクトを作成しました。

「Cursor」ボタンを押してCursorを起動し、プロジェクトフォルダを開きました。

パッケージのインストール - はまった点

暗号化機能を実装するために、DCPcryptパッケージをインストールする必要がありました。ここで重要な発見がありました。

オンラインパッケージの2段階インストール

オンラインからパッケージをインストールする場合、2段階の手順が必要であることが分かりました：

  1. Lazarus自体へのインストール: パッケージマネージャからインストール
  2. プロジェクトへの追加: プロジェクトインスペクタからパッケージを追加

インストール手順

ステップ1: パッケージマネージャからインストール

  1. Lazarusのメニューから [パッケージ] > [オンラインパッケージマネージャ] を開く
  2. DCPcrypt を検索してインストール
  3. Lazarus自体が再コンパイルされ、再起動する

この時点で「インストール完了」と思いがちですが、実はこれだけでは不十分でした。

ステップ2: プロジェクトインスペクタからパッケージを追加

コンパイルを実行すると、「パッケージが見つからない」というエラーが発生しました。

原因は、パッケージをLazarusにインストールしただけでは、個別のプロジェクトで使用できないことでした。

解決方法：

  1. プロジェクトインスペクタを開く（メニュー: [表示] > [プロジェクトインスペクタ]）
  2. プロジェクト名を右クリック
  3. [新規追加] > [新規要件] を選択
  4. インストールしたパッケージ（DCPcrypt）を選択して追加

これで、プロジェクトでDCPcryptパッケージを使用できるようになりました。

学んだこと

  • オンラインパッケージのインストールは2段階: Lazarusへのインストールと、プロジェクトへの追加が必要
  • 再コンパイル・再起動だけでは不十分: パッケージマネージャからインストールして再起動しても、プロジェクトでは使用できない
  • プロジェクトインスペクタが重要: プロジェクトでパッケージを使用するには、プロジェクトインスペクタから明示的に追加する必要がある

Cursorへのプロンプト投入

暗号化テキストエディタの開発は、Geminiで作成したプロンプトを基に進めました。

プロンプト: 暗号化テキストエディタの作成

Geminiで作成したプロンプトをCursorに投入しました。

# Role
あなたはLazarus/Free Pascalのエキスパートエンジニアです。

# Task
シンプルな暗号化テキストエディタを作成してください。
以下の要件をすべて満たすPascalコード（MainFormのユニット全体）を出力してください。

# Requirements
1. UIコンポーネント:
   - TMemo (本文入力用)
   - TButton (保存、開く、クリアの3つ)
   - TSaveDialog / TOpenDialog

2. 暗号化ロジック:
   - ライブラリ: DCPcrypt (DCPrijndael + DCPsha256) を使用。
   - アルゴリズム: AES-256 (Rijndael)。
   - パスワードを鍵として使用し、保存時に暗号化、読み込み時に復号化する。
   - 暗号化されたバイナリデータは、テキストエディタで開けるよう Base64 エンコードして保存すること。

3. 動作フロー:
   - 【保存時】保存ボタン押下後、InputQuery等でパスワードを入力させ、暗号化してファイルへ書き込む。
   - 【読込時】ファイル選択後、パスワードを入力させ、復号してTMemoに表示する。

4. エラー対策:
   - パスワードが間違っている、またはデータが壊れている場合に「復号に失敗しました」と表示する仕組みを含めてください（例：データの先頭に特定の識別文字列 "MYCRYPT" を含めて暗号化し、復号後にそれが存在するかチェックする）。

AIが実装した内容：

  • 暗号化関数: EncryptText - テキストをAES-256で暗号化し、Base64エンコード
  • 復号化関数: DecryptText - Base64デコードしてからAES-256で復号化
  • UIコンポーネント: TMemo、保存/開く/クリアボタン、ダイアログ
  • エラーハンドリング: 識別文字列 "MYCRYPT" を使用してパスワードの正誤を判定
  • パスワード入力: InputQueryでパスワードを入力

ビルドと実行

パッケージの追加が完了した後、ビルドを実行して動作を確認しました。

C:\Lazarus\Lazbuildでビルド

ビルドが成功し、実行ファイル day017_CryptEditor.exe が作成されました。

アプリが正常に動作しています！テキストを入力し、保存ボタンを押すとパスワードを入力して暗号化保存できます。開くボタンで暗号化されたファイルを読み込み、パスワードを入力して復号化できます。

アプリの機能

完成した暗号化テキストエディタには、以下の機能が実装されています：

  • ✅ テキスト入力: TMemoでテキストを入力
  • ✅ 暗号化保存: パスワードを入力してAES-256で暗号化し、Base64エンコードして保存
  • ✅ 復号化読み込み: 暗号化されたファイルを読み込み、パスワードで復号化
  • ✅ エラーハンドリング: パスワードが間違っている場合にエラーメッセージを表示
  • ✅ 通常のテキストファイル: メモ帳などで開くと暗号化された文字列として表示

暗号化の仕組み

AES-256アルゴリズム

  • AES (Advanced Encryption Standard): 強固な暗号化アルゴリズム
  • 256ビット鍵: パスワードをSHA-256でハッシュ化して256ビットの鍵を生成
  • Rijndael: AESの実装アルゴリズム

Base64エンコード

  • バイナリデータのテキスト化: 暗号化後のデータはバイナリ（読めない文字）になるため、Base64エンコードしてテキスト形式に変換
  • メモ帳で開ける: Base64エンコードされたデータは、メモ帳などで開くと「意味不明な文字列」として表示される

セキュリティの向上

  • 識別文字列: データの先頭に "MYCRYPT" を含めて暗号化し、復号後にその文字列が存在するかチェックすることで、パスワードの正誤を判定
  • エラーハンドリング: パスワードが間違っている場合、復号結果がデタラメになるため、識別文字列のチェックでエラーを検出

学んだこと

Day17の開発を通じて、以下のことを学びました：

オンラインパッケージのインストール手順

  • 2段階のインストールが必要:
    1. パッケージマネージャからLazarus自体にインストール（再コンパイル・再起動）
    2. プロジェクトインスペクタから個別のプロジェクトに追加
  • 再起動だけでは不十分: パッケージマネージャからインストールして再起動しても、プロジェクトでは使用できない
  • エラーメッセージから学ぶ: 「パッケージが見つからない」エラーから、プロジェクトへの追加が必要だと気づいた

DCPcryptパッケージの使用

  • 強力な暗号化ライブラリ: DCPcryptは、AES、SHA-256など、様々な暗号化アルゴリズムを提供
  • 簡単な実装: パッケージをインストールすれば、複雑な暗号化処理を簡単に実装できる
  • Base64エンコード: バイナリデータをテキスト形式で保存するためにBase64エンコードが必要

暗号化アプリの実装

  • パスワードベースの暗号化: ユーザーが入力したパスワードを鍵として使用
  • エラーハンドリング: パスワードが間違っている場合の処理が重要
  • 識別文字列: データの整合性を確認するための仕組み

実用的なアプリの作成

  • シンプルなUI: TMemoとボタンだけで、実用的な暗号化エディタが作成できる
  • ファイル形式: 通常のテキストファイルとして保存することで、どこでも開ける（ただし内容は暗号化されている）
